# Public MVP Roadmap

## v0 — local collection

- Read-only wallet activity ingestion
- Snapshot watcher
- SQLite persistence
- Duplicate protection
- Candidate position grouping
- Local dashboard shell

## v1 — personal review loop

- Session intention
- Persistent local trade reviews
- Screenshot-to-trade association with an explicit ambiguity state
- End-of-day review draft
- Trader profile proposals with human approval

## Later

- Stronger market-data enrichment
- Multi-user storage and authentication
- Optional hosted deployment
- Public integrations and contributor workflows

MemeOS will remain local-first until the personal workflow is reliable. No trading execution or wallet signing is planned for this product.
